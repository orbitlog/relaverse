# Relaverse · 关系宇宙

一个无需注册、无需后端的 3D 人际关系图谱。连接重要的人，记录你们如何相遇、一起走过的经历。首次打开仅有「我」，所有个人数据保存在当前浏览器的 IndexedDB 中。

## 本地运行

需要 Node.js 22.12+，推荐 Node.js 22 LTS。

```sh
npm install
npm run dev
```

打开 Vite 输出的本地地址，默认 `http://127.0.0.1:5173`。

```sh
npm test       # 数据完整性、备份校验和避让布局
npm run build # TypeScript 检查与生产构建
npm run preview
```

## 单个 HTML 分享版

```sh
npm run build:standalone
```

生成 `standalone/Relaverse.html`。发送这一个文件即可，接收者用支持 WebGL 的现代桌面浏览器打开，无需安装 Node.js、启动服务器或联网。JavaScript、CSS、3D 引擎、星月夜背景和图标都已嵌入。

该文件是完整应用，不包含开发者或发送者浏览器中的人物资料。接收者从「我」开始创建自己的关系网；需要迁移现有数据时，使用应用内的 JSON 导出与导入。

浏览器对本地文件存储的支持和隔离方式可能不同。使用固定的文件路径和浏览器，定期导出 JSON；改名、移动文件、换浏览器或清理浏览器后，可能需要重新导入备份。部分聊天软件只显示 HTML 文本或预览，需先下载文件，再用浏览器打开。

## 操作

- 默认按住拖动平移整个视图，点击「旋转」按钮后按住拖动旋转；双指滑动或滚轮缩放。完全支持只有单一点击动作的 Mac 触摸板。
- `H` 平移，`R` 旋转，按住空格临时平移，松开恢复原模式。编辑文本或弹窗打开时不触发这些快捷键。
- 单击球体查看档案，双击聚焦，点击「全局视图」框选全部人物。
- 切换「人物」（`V`）模式后拖动球体调整其三维位置；也可用方向键微调。手动布局会被保存。
- 切换「连线」（`C`）模式可从球体拖出关系；人物旁的 `+ 拖出关系` 始终可用。拖动时显示操作状态，按 Esc 取消。
- 从人物旁的 `+` 拖向空白处创建新人，拖向另一球体建立关系。按 Esc 取消。
- 「添加人物」提供键盘可用的创建入口；新人物连接到当前选中的人物，未选择时连接到根人物。
- 点击关系标签编辑名称与说明。同一对人物允许不同关系，同名关系会被阻止。
- 右侧「人物档案」编辑相识过程、日期、地点、城市与备注；「共同经历」新增、编辑和删除记忆。
- 从左侧人物列表或顶部搜索框定位人物；左侧记忆收藏展示所有共同经历。
- 导出 JSON 备份；导入先校验版本、字段、ID、日期与引用，再确认覆盖。删除人物也需确认，并级联删除其关系与经历。「我」不可删除，但可以编辑。

## 数据与隐私

IndexedDB 数据库 `relaverse` 的 `universe` 存储包含完整图谱和视图偏好。修改自动保存；失败会明确提示并提供重试。导出直接读取内存中的最新图谱。个人资料不会上传到服务器。

页面使用梵高《星月夜》原作背景，配合钴蓝玻璃面板与金色人物起点。画作从 Wikimedia Commons 的公共领域复刻取得并保存在本地，出处见 [artwork/ATTRIBUTION.md](./public/artwork/ATTRIBUTION.md)。窄窗口首次打开不默认展开详情面板，点击人物后再查看档案。

浏览器数据与域名、端口、浏览器配置关联；清理站点数据可能删除图谱。请定期导出备份。在其他浏览器或部署域名继续使用时，先导出再导入。

需要支持 WebGL 的现代桌面浏览器。尊重系统的减少动态效果偏好。窄屏支持查看和表单编辑，完整 3D 编辑主要针对 PC。

## 技术与结构

React 19、TypeScript、Vite、Three.js、React Three Fiber、Drei CameraControls、Zustand、Tailwind CSS 4 和 idb。

```text
src/app/                  应用外壳、导航、搜索和备份
src/components/scene/     球体、连线、拖拽投射、相机和 WebGL 降级
src/components/panels/    人物档案、关系与经历编辑、可访问弹窗
src/domain/               关系约束、备份校验和方向约束避让
src/stores/               图谱状态与自动保存队列
src/storage/              IndexedDB 读写
src/types/                数据模型
tests/                    核心数据与布局测试
```

原始需求保存在 [Relaverse_PRD.md](./Relaverse_PRD.md)。图谱备份遵循文档中的 `schemaVersion: 1`。

## 部署

`npm run build` 输出静态文件到 `dist/`，可部署到静态托管平台。本站无后端和云同步；部署站点只提供应用代码。
